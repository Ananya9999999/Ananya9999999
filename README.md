# Featured Projects

## 📈 Options Pricing Engine

A production-style pricing engine implementing multiple derivative pricing models.

### Features

- Black-Scholes analytical pricing
- Greeks computation
- Monte Carlo simulation
- Antithetic Variates
- Geometric Brownian Motion
- Cox-Ross-Rubinstein Binomial Tree
- American & European Options
- Performance Benchmarking

**Highlights**

- Cross-validated multiple pricing models
- High-throughput Monte Carlo implementation
- Investigated and explained hardware cache bottlenecks
- Modular modern C++ architecture

## 📚 Limit Order Book Simulator

A realistic exchange matching engine built from scratch.

### Features

- Price-Time Priority Matching
- Market Orders
- Limit Orders
- FIFO Queue Management
- Order Cancellation
- Performance Benchmarking

**Highlights**

- Matching engine using STL data structures
- Benchmarked throughput under varying market conditions
- Diagnosed and fixed a subtle comparator bug affecting execution priority
